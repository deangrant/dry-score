# Agent commands

Reusable command prompts for this repository. Canonical files live under
[`.agents/commands/`](./); Cursor loads them via
[`.cursor/commands`](../../.cursor/commands) → `../.agents/commands`.

| Command | Description |
| ------- | ----------- |
| [verify](./verify.md) | Run `scripts/verify.sh` lite or full quality gates |
| [dry-dogfood](./dry-dogfood.md) | Clear dry-rs self-scan findings to zero |
| [design-scan](./design-scan.md) | Style + SOLID checklist with fixed report schema |
